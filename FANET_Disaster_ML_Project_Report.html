FANET Disaster Telemetry & Multi-Model ML Benchmark

Project: Real-time UAV Network Status Prediction (Critical, Degraded, Normal) in Disaster Environments

Dataset: FANET Disaster Dataset.csv (5,000 records × 22 columns, 0 missing values)

1. Executive Summary & Models Tested

In post-disaster search-and-rescue missions, ground towers collapse, requiring Flying Ad-Hoc Networks (FANETs) of UAVs to maintain life-saving communications. This project evaluates four machine learning architectures on an identical 80/20 stratified holdout test split (N = 1,000):

  • Random Forest: Bagging Ensemble of 100 deep trees trained on bootstrap samples.
  • Decision Tree: Single Tree baseline optimized via Gini split criteria.
  • SVM (RBF Kernel): Non-linear Maximum Margin kernelized classification.
  • Logistic Regression: Linear Baseline with balanced class weights.

3. Key Technical Takeaways for Group Members

Zero Outages Missed (100% Critical Recall): Tree models (Random Forest & Decision Tree) achieved 100.0% recall on the Critical outage class (0 false negatives out of 607 nodes). In emergency operations, failing to detect a critical outage means an aerial node disconnects without rerouting, jeopardizing rescue communication.
Why Tree-Based Models Outperform SVM & Logistic Regression: Network telemetry transitions operate under physical thresholds (e.g., Latency > 200 ms, Packet Delivery Ratio < 0.65). Decision trees naturally identify these step-function boundaries, whereas linear models struggle to partition non-linear multi-class operational regimes.

Top 4 Most Predictive Features:

  1. Latency (Primary discriminator)
  2. Packet_Delivery_Ratio
  3. Throughput
  4. Link_Stability
